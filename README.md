# RainAlert – Automatic Rain Detection and Clothes Protection System

## Project Overview
RainAlert is an Arduino-based automation project designed to protect clothes from unexpected rainfall. The system detects rain using a rain sensor and automatically activates a mechanism to move clothes to a protected area.

The main objective is to reduce manual effort and prevent clothes from getting wet when rain occurs, especially when people are away from home.

## Objectives
- Detect rainfall automatically using a rain sensor.
- Protect clothes from unexpected rain.
- Reduce manual intervention.
- Develop a low-cost and efficient home automation solution.
- Understand sensor interfacing and relay-based control using Arduino.

## Working Principle
1. The rain sensor continuously monitors the surrounding conditions.
2. When rain is detected, the sensor sends a signal to the Arduino.
3. The Arduino processes the input signal.
4. The relay is activated to control the connected motor mechanism.
5. The mechanism moves the clothes to a protected location.

## Components Used
- Arduino Uno
- Rain Sensor Module
- Relay Module
- DC Motor (for the clothes-moving mechanism)
- Power Supply
- Connecting Wires

## Technologies Used
- Arduino IDE
- Embedded C/C++
- Sensor Interfacing

## Applications
- Automatic terrace clothes protection.
- Smart home automation.
- Rain detection systems.
- Sensor-based control applications.

## Project Outcome
RainAlert demonstrates how sensor-based automation can be used to develop a practical home solution that protects clothes from unexpected rainfall while reducing the need for manual monitoring.
